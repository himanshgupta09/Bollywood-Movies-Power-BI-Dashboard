# Bollywood-Movies-Power-BI-Dashboard
An interactive Power BI dashboard that analyzes Bollywood movie data using KPIs, charts, filters, and DAX measures to provide insights into box office performance, IMDb ratings, genres, directors, OTT platforms, and profitability.
# 🎬 Bollywood Movies Data Analytics Dashboard

## 📌 Project Overview
This Power BI dashboard provides interactive insights into Bollywood movies by analyzing budgets, box office collections, IMDb ratings, genres, directors, lead actors, release years, and OTT platforms.

The project demonstrates data cleaning, data modeling, DAX calculations, and interactive dashboard development using Microsoft Power BI.
